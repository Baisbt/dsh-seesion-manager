# 方案与执行：浅色外观下的可读性

> 状态：**已落地并自检通过**（2026-11-15）。全部在 Client 半；四条建议全采纳（行细线 / 表头带 / 列竖线常驻 / 吸顶表头）。
> 待你在浅色下实机确认后可能还要调一轮数值。

## 1. 从浅色截图读到的六个问题

1. 整页只有两条头发丝线（树与列表之间、表头下方），其余全靠留白 → 第一眼"淡"。
2. 表头、创建/最后活动/大小三列、行内第二行、树里的大小 —— 全部压在最浅两档文字色上，几乎同色。
3. 勾选框是 1px 最浅边框，白底上接近消失。
4. 操作列的底纹用的是宿主"第一/二层底"，浅色下与白底差 1~2%，整列像浮空。
5. 列竖线只在 hover 出现且是浅灰 → 一行里的字段读起来像连续文字。
6. 表格只有 7 行，下方大片空白，脚注孤零零贴底 → 没有"表格到此为止"的感觉。

外加一处**结构性 bug**：列设置面板与右键菜单的底色写死成深灰，而文字跟随主题 → 浅色下是深底深字。

## 2. 改动

### 2.1 一套按主题分叉的取值（集中在一处）

深色仍用"白色叠加"，浅色改用"黑色叠加 + 真对比的线"。新增的主题变量：

| 变量 | 深色 | 浅色 |
| --- | --- | --- |
| 表头带 | 3% 白 | **4% 黑** |
| 行分隔线 | 4.5% 白 | **7% 黑** |
| 行的间距 / 圆角 | 2px / 8px | **0 / 0**（读作真正的表格） |
| 操作列底纹（行 / 表头） | 4% / 6% 白 | **3.5% / 5% 黑** + 左侧 1px 线 |
| 列竖线颜色 / 静止可见度 / 高度 | 第三档边框 / 0（hover 才现） / 16px | **14% 黑 / 常驻 / 22px** |
| 面板分隔线（树、工具栏竖线、表头下缘） | 第一档边框 | **10% / 13% 黑** |
| 脚注带 | 2% 白 | **2% 黑** |

### 2.2 文字与控件分级（仅浅色）

表头、创建/最后活动/大小、工作区标签：最浅档 → **中间档**；操作图标：最浅档 → 中间档；
空状态文字：最浅档 → 中间档；未选中的勾选框：**1.5px 中间档边框**；
勾选行：9% → **14% 主题蓝**；树选中项：**12% 主题蓝**；已归档药丸：白 5% → **黑 4.5% + 第二档边框**。

### 2.3 修掉"深底深字"

列设置面板、右键菜单改用宿主的浮层色（浅色下白底深字）；Toast 在浅色下改浅底深字 + 边框。

### 2.4 吸顶表头（顺带根治错位）

表头移进列表的滚动容器内并 `position: sticky`：
- 表头与行共用同一个可用宽度，**竖向滚动条不再让右侧列整体左移**；
- 行的左右内边距改成外边距（6 / 12），行的内缩仍是 8 → 网格起点仍是 14 / 20，与表头完全一致；
- 表头带为不透明底，行从下面滚过不会透出文字；
- 行加 `scroll-margin-top: 44px`，定位到某行时不会被表头压住。

### 2.5 主题跟随

启动时读宿主底色判断深/浅，之后用轻量监听（根节点 class/style/data-* 变化 + 系统配色偏好变化）实时更新，切主题不用刷新。
